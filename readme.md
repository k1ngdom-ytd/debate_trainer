# 观点辩论训练

基于知乎真实讨论的 AI 辩论陪练工具 · 知乎黑客松 2026 参赛作品

---

## 📌 项目简介

「观点辩论训练」是一个帮助用户提升逻辑思维和表达能力的 AI 辩论工具。

你选择一个立场，AI 站在你的对立面。它不会尖酸刻薄，而是用严密的逻辑为你拨开迷雾，帮你从多角度审视问题。你会发现，那些看似不可调和的矛盾背后，都存在着合理的立场。

**它不教你驳倒别人，而是帮你在理性与现实的碰撞中，拓宽自己的认知边界。**

---

## 🎯 核心功能

- **知乎搜索**：输入辩题，获取知乎真实讨论
- **弹药库提炼**：AI 自动提炼正反方核心论据
- **三回合辩论**：用户先立论，AI 后反驳，模拟真实辩论节奏
- **AI 风格选择**：温和引导 / 犀利攻击 / 逻辑严谨
- **计时器**：每回合限时，锻炼临场反应
- **快捷回复建议**：不知道说什么时，AI 帮你生成反驳思路
- **复盘报告**：3 回合后生成能力评估与改进建议
- **热点辩题**：一键获取知乎热榜话题
- **社交关系**：查看关注列表与粉丝列表
